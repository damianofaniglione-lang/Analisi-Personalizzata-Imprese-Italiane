# Analisi-Personalizzata-Imprese-Italiane
Progetto di analisi e trasformazione dati economici/occupazionali in Italia (2025-2026) sviluppato in Python e Pandas.
## Descrizione del Progetto
Questo progetto analizza l'andamento temporale e la distribuzione geografica di indicatori economici e occupazionali in Italia nel periodo 2025-2026. L'obiettivo è identificare i settori industriali trainanti e comprendere l'impatto della stagionalità sul mercato italiano.

## Tech Stack & Competenze Dimostrate
*   **Linguaggio:** Python
*   **Librerie Principali:** Pandas (Data Manipulation), NumPy (Calcolo numerico), Matplotlib & Seaborn (Data Visualization).
*   **Data Cleaning:** Gestione dei formati Wide/Long, filtering di aggregati macro, strutturazione serie temporali (Unpivoting/Melting).
*   **Ambiente:** Google Colab

## Sviluppi Futuri / KPI Analizzati
1.  **Trend Temporale:** Evidenziata la fluttuazione mensile con analisi dei minimi storici (es. periodo estivo).
2.  **Scomposizione Ateco:** Classificazione delle macro-aree produttive più attive.
